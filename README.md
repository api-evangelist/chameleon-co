Chameleon is an in-product guidance platform that enables product and growth teams to build, manage, and optimize onboarding tours, tooltips, modals, launchers, and microsurveys without engineering effort. Its REST API and JavaScript SDK allow teams to programmatically manage experiences, target users by segment, trigger tours from custom events, and retrieve engagement analytics and survey responses. Webhooks provide real-time event delivery when users interact with any Chameleon experience. The platform scales across Startup, Growth, and Enterprise plans based on Monthly Tracked Users (MTUs).
