Chameleon uses an embedded card on the Integrations page to announce an update, delivered exactly where users are already managing their connected tools. The card is built using Chameleon's embeddable card type, which gives it full-width banner-like presence while supporting richer media options. New users are filtered out because they configure the integration from scratch and already get the updated permissions as part of the default setup.
